# Demo data asset attribution

All room/table covers and detail photos under `assets/photos/`, and all
panoramas under `assets/panoramas/`, are **third-party photographs, not
photographs of the synthetic demo business**. They are used only as
representative demo/vitrine imagery inside the demo backup package. The
business names, people, prices and orders in the package remain synthetic.
The same source image may appear on more than one room or table.

The 20 photo files use CC BY 4.0, CC BY 2.0, CC0 1.0 and public-domain
sources. The 10 panorama files use CC BY 4.0 NOIRLab/NSF/AURA/CTIO sources.
CC BY requires attribution and a note of changes; CC0/public domain do not
require attribution, but source and author information is preserved here and
in the package. No endorsement by the authors or institutions is implied.

## Where attribution appears in a package

- `assets/MEDIA_ATTRIBUTION.txt` — combined human-readable notice shipped
  inside every backup folder that contains media. It lists every source's
  author, license, source URL, changes and local file paths.
- `assets/room-media/manifest.json` and `assets/table-media/manifest.json` —
  each media `title` names the author and the license.
- `scripts/demo-data/demo-data-manifest.json` — package-level media inventory
  with source URLs, authors, licenses, modification notes and file hashes.
- The desktop media picker/list shows the stored `title`, so the attribution is
  visible to users who inspect the media.

## Optional Teknikel pack D — source catalog photography

Pack D copies originals at generation time from the external local
`teknikel_catalog_prep/images-original/` archive; these files are not added to
this repository. Its `image-manifest.json` supplies public Teknikel catalog
source URLs, associated SKUs and SHA-256 values. The generator verifies each
source and copied file and packages `assets/TEKNIKEL_SOURCE_MANIFEST.json`
with per-file provenance, hash and MIME format.

These are real public catalog photographs, **not synthetic artwork and not
open-licensed media**. Rights remain with the original owners. Demo review use
does not imply a redistribution license. All 68 original files are retained
across 35 products; two files of the same Kalisto board have identical bytes
(67 unique hashes), so the canonical gallery reader deduplicates those by hash.
The open-license/synthetic statements for A-C above do not apply to D.
