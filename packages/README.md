# Paketler

Bu klasör uygulamalar arasında paylaşılan modüler paketleri içerir.

- `shared`: Ortak veri tipleri ve yardımcılar.
- `web-widget`: Web sitelerine eklenebilir Yardımcı Asistan widget'ı.
- `ai-core`: Provider bağımsız AI altyapısı.
- `whatsapp-bridge`: WhatsApp link, manuel kopyalama ve WebView destekleri.
- `sync-core`: PC uygulaması ile firma hostingi arasındaki veri alışverişi.
