# Shared

Yardımcı Asistan uygulamalarında ortak kullanılacak veri tipleri ve yardımcı fonksiyonlar bu pakette yer alır.

Bu paket framework bağımsızdır. Web, desktop, Android bridge katmanları, mini API yardımcıları ve testler aynı veri dilini buradan kullanmalıdır.

## Komutlar

```bash
npm run build
npm test
```
