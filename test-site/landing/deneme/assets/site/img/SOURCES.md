# Demo test sitesi: sabit tasarım fotoğrafları

Bunlar sadece demo test alanındaki sabit tasarım görselleridir; gerçek işletme
fotoğrafı veya yayınlanmış efekt örneği değildir. Orijinalleri değil, Wikimedia
Commons sitesinden 2026-11-02'de alınan 1280px önizlemeleri kullanılır.
Resimler sonraki düzenleme aşaması için efekt sahnesi olmadan yerleştirilmiştir.
